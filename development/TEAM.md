# Equipo y capacidades necesarias

> **Estado: TO INVESTIGATE.** Los roles describen capacidades, no personas asignadas ni contrataciones aprobadas.

| Capacidad | Responsabilidad durante descubrimiento |
| --- | --- |
| Product discovery | Entrevistas, problema, priorización, métricas y modelo comercial. |
| Especialista de infraestructura | Validar operaciones, fabricantes, topologías, datos y casos de uso. |
| Arquitectura / plataforma | Evaluar integración, datos, multi-tenancy, despliegue y escalabilidad. |
| Seguridad | Modelar amenazas, controles, requisitos regulatorios y acceso de terceros/agentes. |
| Ingeniería de conectores | Investigar APIs, SNMP, logs, compatibilidad, pruebas y mantenimiento. |
| IA / experiencia conversacional | Definir consulta natural, trazabilidad, guardrails y MCP. |
| Operaciones / soporte | Validar operabilidad, soporte, observabilidad y coste de servicio. |
